## Copy

- Tagline: Bind a clear sign-off to the current PR commit.
- Summary: Signlight adds a separate red, green, and yellow business or release
  sign-off to pull requests. An authorized GitHub user signs the exact HEAD SHA;
  a new commit makes the status stale until it is signed again.
- Intended use: lightweight business-owner, release-owner, policy-file, or
  documentation acknowledgement alongside—not instead of—GitHub code review.
- Limitation: not a legal signature, compliance product, or defense against a
  malicious repository administrator.
- Categories: Code review; Utilities.
- Keywords: sign-off, approval, pull request, stale, release, acknowledgement.

## Highlights

1. **See current sign-off instantly** — red unsigned, green signed, yellow after
   a new commit, with a text label in every state.
2. **Trust GitHub identity and immutable SHAs** — exact commands use the event
   actor and bind the record to the current PR HEAD.
3. **No external service** — state stays in GitHub; there is no account, backend,
   database, or external data transfer.
